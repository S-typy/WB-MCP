# Снимок 2026-09-28

`catalog.json` — каталог операций API продавца Wildberries, собранный из OpenAPI-спецификаций
портала dev.wildberries.ru по состоянию на 28.09.2026: методы, пути, хосты и песочница,
допуск по категориям и типам токена, таблицы лимитов, признаки, схемы аргументов и ответов.
Текстов документации WB здесь нет, только заголовки методов; сами спецификации в пакет
не входят.

Сервер при запуске берёт самый свежий снимок. Если у вас есть собственная копия
спецификаций (по файлу на раздел, как их отдаёт портал), подложите каталог с ними через
`--specs` или переменную `WBMCP_SPECS`: тогда описания методов и полей будут полными.
