# Изменения

## 0.1.0 — 2026-09-30

Первая версия. Что умеет:

- каталог из 305 операций API продавца WB, собранный из спецификаций от 28.09.2026;
  поиск, карточка операции, сырой вызов и инструмент на каждую операцию по профилям;
- допуск по токену до запроса: категории, только чтение, тип токена, срок, песочница;
- лимиты WB по таблицам из спецификаций, штраф за 4XX, заголовки X-Ratelimit, ожидание
  при нехватке квоты;
- записи через журнал: dry_run, повтор только с force, подтверждение опасных действий;
- кэш ответов чтений с правилами TTL, большие ответы в файл с образцом в ответе и срезами
  через wb_result;
- готовые инструменты: заказы FBS (новые, все, статусы, стикеры, поставки), карточки,
  склады, цены с ожиданием итога, остатки, отзывы и вопросы с ответами, чат с покупателями,
  возвраты, реклама и её статистика, поставки FBW и план приёмки, баланс, тарифы, отчёты;
- HTTP-режим с ключами клиентов, Postgres для нескольких экземпляров, общий лимитер в Redis;
- образ Docker и переменная WBMCP_DATA_DIR для тома с данными.
